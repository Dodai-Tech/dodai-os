# dodai-os-s3-amoled-206

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/Dodai-Tech/dodai-os/blob/main/LICENSE)

Part of [Dodai OS](https://github.com/Dodai-Tech/dodai-os).

Firmware for the Waveshare ESP32-S3-Touch-AMOLED-2.06 on `esp-hal`: no ESP-IDF, `no_std`. Not a workspace member: it needs the Xtensa toolchain (`espup install`). Install next to the native firmware with `just native-install`, go back with `just native-restore`.
