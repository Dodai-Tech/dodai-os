# hibari-os-shell

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/Dodai-Tech/hibari-os/blob/main/LICENSE)

Part of [Hibari OS](https://github.com/Dodai-Tech/hibari-os).

The shell view: status bar, app grid, app page and the slide transitions between them, drawn through [`fusuma-render`](https://crates.io/crates/fusuma-render)'s `Renderer` trait. The same code draws on a microcontroller display and in a host window. `no_std`.
