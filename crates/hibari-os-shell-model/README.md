# hibari-os-shell-model

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/Dodai-Tech/hibari-os/blob/main/LICENSE)

Part of [Hibari OS](https://github.com/Dodai-Tech/hibari-os).

Shell logic with no UI toolkit: which apps the launcher shows, paging, hit testing and navigation. A view draws it, so the same logic can serve Hibari OS and a desktop environment. `no_std`.
