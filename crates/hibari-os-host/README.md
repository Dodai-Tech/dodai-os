# hibari-os-host

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/Dodai-Tech/hibari-os/blob/main/LICENSE)

Part of [Hibari OS](https://github.com/Dodai-Tech/hibari-os).

Runs the shell on a desktop for development: device profiles (S3 AMOLED, round watch, 7 inch panel, headless, desktop), a host clock and framebuffer, PNG screenshots with `--tap` and `--at`, and an optional window (`--features window`).
